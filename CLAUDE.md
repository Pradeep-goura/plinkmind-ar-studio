# Project rules
- Frontend: React + TypeScript + Vite + Tailwind. Backend: Supabase only.
- No Next.js, Express or other backend frameworks without approval.
- Never commit secrets or .env.local. Only publishable keys in the browser.
- Do not claim a feature works until it is implemented and tested.
- One phase at a time; stop and wait for approval after each phase.
- Design theme is PROVISIONAL until the official logo/brand assets are added.
